# Форк presentation-skill под библиотеку слайдов «Пульс»

Форк [siril9/presentation-skill](https://github.com/siril9/presentation-skill) v0.11.0,
настроенный на шаблон `1_ХОРОШИЕ_ПРИМЕРЫ` (82 слайда, 66 выбираемых каркасов
в 11 категориях).

```bash
npm install
npm run pulse:check      # проверить оформление
npm run pulse:build      # собрать пример
```

## Два файла для дизайнеров

Всё оформление и все правила живут в двух файлах. Код для их правки трогать
не нужно.

| Файл | Что в нём |
| --- | --- |
| **[pulse/DESIGN_RULES.md](pulse/DESIGN_RULES.md)** | правила: когда какой каркас, лимиты, чего нельзя |
| **[pulse/theme.json](pulse/theme.json)** | цвета, шрифты, кегли, сетка, отступы, палитра графиков |

`theme.json` — единственный источник правды по оформлению. Его читают обе
половины скилла: `templates/pptxgenjs/pulse_theme.js` и
`scripts/pulse_theme.py`. Ни один цвет, кегль или отступ в коде не продублирован.

После правки:

```bash
npm run pulse:check
```

Проверка сообщает об ошибках по-русски и в терминах файла — например
`colors.accent = "#005AFE" — нужен HEX из шести символов без решётки`,
`type_scale_pt: "subtitle" (18) меньше "body" (30)`,
`шапка (до 1.9) налезает на контент (начинается с 1.75)`.

## Единственная тема

Тема называется `pulse-library` и рендерится **всегда**. Другую выбрать нельзя:

| Попытка | Результат |
| --- | --- |
| без флага, `--style-preset auto` | `pulse-library` |
| `--style-preset midnight-neon` | `pulse-library` + предупреждение |
| `deck_style.style_preset` в outline | игнорируется |
| `deck_style.palette_key` / `font_pair` | игнорируются |
| `design_brief.json` с темой | `pulse-library` |

Имя темы не отвергается ошибкой, а принимается, логируется и переопределяется —
существующие вызовы не ломаются. Остальные 13 пресетов апстрима остаются в
`PRESETS`, чтобы каталоги и тесты резолвились.

Переключатели (менять **вместе**):

```
templates/pptxgenjs/presets.js   FORCED_PRESET_NAME
scripts/design_tokens.py         FORCED_STYLE_PRESET
```

`null` / `None` возвращает штатный выбор темы.

## Что взято из шаблона

Все значения измерены по файлу, а не подобраны.

**Сетка.** Поля 0.68″. Полоса шапки 0.49″–1.43″ — одинакова на 58 каркасах из
66. Контент с 1.75″.

**Цвет.** Основной текст `111111` (1348 употреблений), подложка `EAF1FF`,
акцент `005AFE`. Ни одного слайда с тёмным или полноэкранным фоном — тема
светлая целиком, панели тонируются, а не инвертируются.

**Шрифт.** `SB Sans Display` и `SB Sans Text`.

**Кегли.** 24 / 18 / 14 / 12 / 10 / 9 pt на слайде 13.333″.

**Графики.** 22 диаграммы: 11 столбчатых, 6 кольцевых, 4 линейных, 1 с
областями. Легенда только на 3 из 22, поэтому по умолчанию выключена. Палитра
серий — из самих диаграмм.

**Лимиты.** Со служебного слайда «Workflow, лимиты и PASS / FAIL»: 1–6 блоков,
до 4 мини-графиков, до 3 линий, donut на 3–5 сегментов, до 3 аннотаций.

## Система координат

`theme.json` написан в единицах, которые дизайнер видит в PowerPoint: дюймы на
слайде 13.333 × 7.5 и пункты при этом размере. Рендерер верстает в 10 × 5.625″.
Оба 16:9, коэффициент 4/3, пересчёт делает загрузчик. Слайд визуально
идентичен; в свойствах файла размер будет 10 × 5.625″.

## Что проверено

- Сборка на всех вариантах: буллеты, карточки, KPI, сравнение, таймлайн,
  таблица, диаграмма, разделы, титул, источники.
- Диаграммы: столбчатая, линейная, кольцевая, с областями — цвета из
  `theme.json`, подписи значений, без легенды, без рамки.
- Тема форсируется на всех маршрутах: явный флаг, outline, design_brief.
- `npm run pulse:check`, `check:node`, `check:python`,
  `sync_plugin_snapshot --check` — проходят.

Не проверено локально: тесты, требующие `python-pptx` (`check:role-systems`,
`check:layout-lint`, `check:accessibility`) — в песочнице pip без сети.
Прогоните их после `npm run setup:python`.

## Логотип

Шаблон не несёт логотип на мастере, поэтому вордмарк не ставится. Если он
нужен — положите `pulse/assets/logo.png`, и он появится в футере каждого
слайда автоматически.
