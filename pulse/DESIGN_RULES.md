# Правила сборки презентаций «Пульс»

Этот файл — правила, по которым генератор собирает слайды. Он написан для
дизайнеров: править его можно без программиста, код читать не нужно.

**Что где лежит:**

| Файл | Что в нём | Кто правит |
| --- | --- | --- |
| `pulse/DESIGN_RULES.md` | этот файл: правила, лимиты, когда какой каркас | дизайнер |
| `pulse/theme.json` | цвета, шрифты, кегли, отступы, сетка | дизайнер |
| остальной репозиторий | код сборщика | разработчик |

Правки в этих двух файлах меняют результат сборки. Менять код для смены цвета,
кегля или отступа не нужно.

Источник правил — сам шаблон `1_ХОРОШИЕ_ПРИМЕРЫ`: 82 слайда, из них 66
выбираемых каркасов в 11 категориях, плюс служебные слайды с лимитами. Все
числа ниже взяты оттуда, а не придуманы.

---

## 1. Главные принципы

Из служебного слайда «Workflow, лимиты и PASS / FAIL»:

1. **Сначала прочитайте весь контент и ограничения.** Сохраните факты,
   значения, единицы, даты, имена и причинные связи.
2. **Один слайд — один вывод.** И один главный визуальный объект.
3. **Каркас выбирается по форме данных и числу элементов**, а не по вкусу.
4. **Сетка перестраивается под реальное число элементов.** Пустых слотов быть
   не должно.
5. **Рендер, структура и смысловая проверка должны дать PASS.** При FAIL —
   вернуться к ошибочному шагу или взять запасной каркас.

## 2. Жёсткие лимиты

Заданы в `pulse/theme.json` → `limits`. Генератор их проверяет.

| Лимит | Значение |
| --- | --- |
| Блоков на слайде | 1–6 |
| Мини-графиков на слайде | до 4 |
| Линий на линейном графике | до 3 |
| Сегментов в кольцевой диаграмме | 3–5 |
| Аннотаций на слайде с интерфейсом | до 3 |
| Выводов на слайде | ровно 1 |

Превышение лимита — это FAIL. Не ужимайте кегль, чтобы влезть: разнесите на
два слайда или укрупните группировку.

---

## 3. Категории слайдов

Одиннадцать категорий из шаблона. Для каждой — зачем она и как применять
(формулировки из слайдов-разделителей шаблона).

### Открытие и навигация — `opening`

**Для чего:** задают контекст презентации и помогают аудитории сразу понять её
маршрут.
**Как применять:** выберите титул или повестку под задачу. В начале оставьте
только необходимое.

### Текст и аргументация — `text`

**Для чего:** доносят один тезис, показатель или аргумент без визуальной
конкуренции.
**Как применять:** сформулируйте один вывод. Оставьте только доказательства,
которые его поддерживают.

### Карточки и колонки — `cards`

**Для чего:** сравнивают равноправные направления, варианты и преимущества.
**Как применять:** подберите каркас под число элементов и пересоберите сетку
без пустых мест.

Самая большая категория — 16 каркасов. Сетка выбирается по числу элементов:

| Элементов | Каркас |
| --- | --- |
| 2 | симметричная пара |
| 3 | три равнозначные карточки во всю ширину |
| 4 | сетка 2 × 2, либо один главный блок + три |
| 5 | сетка без пустого слота |
| 6 | полная сетка 3 × 2, либо компактный вариант для коротких тезисов |
| 8 | две смысловые группы |
| 10 | сначала сгруппировать в 5 тем, потом верстать |

Больше шести блоков на одном слайде не бывает: группируйте или разносите.

### Иллюстрации и иконки — `images`

**Для чего:** показывают человека, ситуацию, кейс или визуальную историю через
один фокус.
**Как применять:** сохраните пропорции и кроп. Текст — поддержка изображения,
а не наоборот.

### Графики — `charts`

**Для чего:** сравнивают значения, структуру или динамику и отвечают на один
вопрос.
**Как применять:** сначала сформулируйте вывод. Подпишите единицы, период и
источник данных.

Выбор типа — по вопросу, на который отвечает слайд:

| Вопрос | Тип |
| --- | --- |
| Из чего состоит целое | кольцевая, 3–5 сегментов |
| Как менялось во времени | линейный, до 3 линий |
| Чем отличаются категории | столбчатый |
| Как накапливается объём | с областями |
| Несколько равнозначных метрик | до 4 мини-графиков в сетке |

### Таблицы — `tables`

**Для чего:** показывают точные параметры, статусы и построчные сравнения.
**Как применять:** оставляйте только читаемые строки. Обзор и детали лучше
разнести по разным слайдам.

### Таймлайны и процессы — `timelines`

**Для чего:** показывают порядок этапов, даты, владельцев и зависимости.
**Как применять:** один шаг помещайте в один блок. Плотный план выносите на
продолжение.

### Схемы и продуктовые планы — `schemes`

**Для чего:** объясняют связи между частями системы и желаемое состояние
продукта.
**Как применять:** показывайте одну логику за раз. Сократите подписи и не
проводите связи через текст.

### Интерфейсы и инструкции — `ui`

**Для чего:** объясняют действие в продукте или рабочий шаг на конкретном
экране.
**Как применять:** показывайте один экран или шаг достаточно крупно.
Оставляйте до трёх аннотаций.

### Комбинированные слайды — `combined`

**Для чего:** главный факт поддерживают независимые данные.
**Как применять:** главному компоненту — большая часть внимания. Поддержка
отвечает на отдельные вопросы. Например: один KPI дополняется компактной
динамикой, число остаётся главным акцентом.

### Завершение и обратная связь — `closing`

**Для чего:** фиксируют следующее действие: вопрос, контакт, ссылку или призыв.
**Как применять:** оставьте одно очевидное действие. Проверьте контакт, ссылку
или QR-код.

## 4. Оформление

Все значения — в `pulse/theme.json`. Здесь — смысл, там — числа.

### Цвет

Шаблон **полностью белый**: ни одного слайда с тёмным или полноэкранным фоном.
Поэтому:

- фон слайда всегда белый;
- выделение — подложкой `surface`, а не инверсией;
- акцент `accent` — рейлы, ключевые числа, ссылки;
- основной текст — `ink` (это `111111`, а не чистый чёрный).

### Шрифт

`SB Sans Display` для заголовков, `SB Sans Text` для текста. Оба должны быть
установлены на машине, где идёт сборка, иначе PowerPoint подставит свой и
вёрстка поедет.

### Сетка

Поля 0.68″ слева и справа. Заголовок занимает полосу 0.49″–1.43″ — одинаково
на 58 каркасах из 66. Контент начинается с 1.75″.

Полосы **фиксированные**. Заголовок не «переливается» вокруг длинного текста:
длинный заголовок ужимается внутри своей полосы. Это повторение и делает
слайды узнаваемыми.

### Кегли

Заданы в `type_scale_pt` в пунктах для слайда 13.333″ — ровно так, как их
показывает PowerPoint.

---

## 5. Как изменить оформление

**Поменять цвет:** `pulse/theme.json` → `colors`. Шесть HEX-символов без
решётки.

**Поменять кегль:** `pulse/theme.json` → `type_scale_pt`. В пунктах.

**Поменять поля или сетку:** `pulse/theme.json` → `grid_in`. В дюймах.

**Поменять палитру графиков:** `pulse/theme.json` → `charts.series`. Порядок
важен: первый цвет — первая серия.

**Поменять лимиты:** `pulse/theme.json` → `limits`.

**Поменять правила выбора каркаса:** этот файл, раздел 3.

После любой правки:

```bash
npm run pulse:check
```

Проверит `theme.json` на ошибки (опечатки в цветах, отрицательные отступы,
пропущенные ключи) и покажет, что именно не так.

---

## 6. Чего делать нельзя

- Уменьшать кегль, чтобы влез текст. Сокращайте текст или делите слайд.
- Оставлять пустые слоты в сетке. Пересоберите под реальное число элементов.
- Ставить два главных объекта на слайд.
- Проводить связи схемы через текст.
- Использовать тёмный фон — в шаблоне его нет.
- Ставить больше трёх аннотаций на экран интерфейса.
